# セッションを読む・検索する

Sessions Viewer は対応する JSONL と opencode SQLite の記録を読みやすい会話として表示します。アダプターが認識する記録済みメッセージ、ツール、思考、diff、画像が対象です。欠けた記録の復元や CLI 画面の完全な再現はできません。

![Sessions Viewer で再現した Claude Code のセッション。ツール呼び出しが結果と対応づけられ、diff が描画されている](/screenshots/chat.png)

## 何が復元されるか

### ツール呼び出しと結果の対応づけ

ファイル上では呼び出しと結果は別々のレコードで、離れた行にあることも多く、id で結びついています。バラバラでは読めません。並べて初めて、エージェントが何を要求し何が返ってきたかが分かります。

### 思考ブロックは必要になるまで折りたたみ

拡張思考は回答本体より長いことも珍しくありません。対応する記録済みブロックを折りたたみ、1 件ずつでもセッション全体でも展開できます。連続する推論ステップはコンパクトな 1 行にまとめられます。全体設定とセッションごとの設定で、ツール呼び出しとは独立して推論の表示・非表示を切り替えられます。

### diff は diff として描画

ファイル編集の結果が構造化されたパッチデータを持つ場合、エスケープされたテキストの塊の代わりに、行番号とシンタックスハイライト付きの本物の diff になります。そのデータのディスク上の形は [Claude Code のページ](/ja/agents/claude-code#structured-diffs)を参照してください。

### 画像は元の位置に

貼り付けたスクリーンショットを base64 で保存するエージェントもあれば、別のメディアファイルとして保存するエージェントもあります。どちらも元のメッセージ内にインラインで描画されます。

### Mermaid 図・表・数式

エージェントが markdown として出力したものは markdown として描画されます。

## タスクセッションにスターを付ける {#starred-sessions}

プロジェクトのセッション一覧で行にマウスを重ねると、タイトル横に星ボタンが表示され、スターを付け外しできます。行内にキーボードフォーカスがある場合も表示します。ツールバーの**スターのみ**で未登録のセッションを隠し、もう一度押すと戻します。ピン留めとは独立しており、通常の並び順は変えません。

対象は現在のエージェントとプロジェクトです。最初のページだけでなく、残りのセッション情報も読み込んで絞り込みます。検索・並べ替えとも組み合わせられますが、検索の件数制限は残ります。スターは分割ペイン間で共有し、Sessions Viewer がこの端末に保存します。元の記録や DB は変更しません。安定したセッション ID があれば、リネームや保存パス変更後も維持します。別端末への同期や会話エクスポートには含まれません。プロジェクト切り替えでフィルターはリセットしますが、スターは残ります。

## メッセージを探す {#finding-a-message}

![Sessions Viewer のグローバル検索。複数のプロジェクトにまたがるヒットが並んでいる](/screenshots/search.png)

`⌘⇧F` は**選択中エージェントのプロジェクト**を横断して検索します。7 種類の同時検索ではありません。キーワードではタイトルと保存済み**ユーザーメッセージ本文**を、ID モードではセッション ID を照合します。本文ヒットは対応するユーザーメッセージを開きます。タイトル／ID ヒットはセッションを開き、本文への移動を保証しません。

### 検索範囲と制限 {#search-scope}

グローバル検索は回答、思考、ツール引数・結果、プロジェクトパスを照合しません。別の履歴を探すにはエージェントを切り替えます。通常検索はアーカイブとゴミ箱を含まないため、[Codex のアーカイブ](/ja/guide/codex-session-viewer#archived)や[ゴミ箱](/ja/features/export-and-trash)を確認してください。バックエンドは最大 200 セッション、モーダルは最大 80 件を表示し、完全な全文出力ではありません。

表示は対応する記録済みフィールドに限られます。例えば opencode のツール出力が 30 行を超えると残り行数の注記付きで短縮されます。完全な保存には元ファイルやデータベースを残してください。[解析済みメッセージの保存](/ja/features/export-and-trash)はネイティブのバックアップではありません。

`⌘F` は現在開いているものの中を検索し、`⌘G` と `⌘⇧G` でヒットを行き来します。

### プロンプトへジャンプ

長いセッションの大半はエージェントの出力です。プロンプト一覧はそれをすべて取り除き、自分が入力したものだけを順番にコンパクトに並べます。セッションがどこからおかしくなったかを見つけるのに、たいていこれがいちばん速い方法です。選べばその位置までスクロールします。

### 閲覧履歴

最近読んだセッションはプロジェクトごとの履歴に残り、タイトルで検索できます。昨日のセッションを開き直すのに、探し直す必要はありません。元ファイルが変更されるとプレビューも更新され、Pi のプレビューには最新のユーザーメッセージが使われます。

### 大きな Pi セッション

Pi の記録を開くと、まず最新のメッセージページを読み込みます。上へスクロールすると、さらに古いメッセージが必要に応じて読み込まれます。検索、プロンプトへのジャンプ、グローバル検索、エクスポートでは、必要に応じて全履歴を読み込みます。

## 書き戻しは一切ありません

履歴の閲覧と検索は元の記録を書き換えません。ローカル設定やキャッシュは書く場合があります。リネーム、ゴミ箱／復元、続行、編集機能は別の書き込み操作です。[プライバシーとデータの扱い](/ja/guide/privacy)を参照してください。

検索と opencode 表示の制限は 2026-10-06 に Sessions Viewer 0.6.0 の[検索 UI](https://github.com/jerrywu001/cc-sessions-viewer/blob/69e0b4f/src/modals/GlobalSearchModal.vue)、[コマンド](https://github.com/jerrywu001/cc-sessions-viewer/blob/69e0b4f/src-tauri/src/lib.rs)、[検索処理](https://github.com/jerrywu001/cc-sessions-viewer/blob/69e0b4f/src-tauri/src/agents/mod.rs)、[opencode アダプター](https://github.com/jerrywu001/cc-sessions-viewer/blob/69e0b4f/src-tauri/src/agents/opencode.rs)で確認しました。実際の CLI 動作検証ではありません。
